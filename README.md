## ⚡ DEPLOYMENT PROTOCOLS

### Prerequisites
- **Rust 1.91+** (stable toolchain)
- **Cargo** (package manager)

### Build All Projects
```bash
cargo build --all --release
```

### Run Tests
```bash
cargo test --all
```

### Run Benchmarks
```bash
cargo bench --all
```

### Lint & Format
```bash
cargo clippy --all-targets --all-features
cargo fmt --all
```
